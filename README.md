# gilam-erp-frontend
Gilam savdo majmualarining savdo holatini avtomatlashtiruvchi dasturiy ta'minot front qismi

## Texnologiyalar
- React (Vite)
- Tailwind CSS v4
- shadcn/ui (base-nova stil, Base UI asosida) — `npx shadcn@latest add <komponent>`
- Redux Toolkit + React Redux (holat boshqaruvi)
- React Router (sahifalar navigatsiyasi)
- axios (API so'rovlar)
- recharts (grafiklar)
- date-fns, dayjs, react-day-picker (sana bilan ishlash)
- Geist Variable (shrift)
- lucide-react, @hugeicons/core-free-icons (ikonalar)

`@/` — `src/` papkasiga yo'l alias (jsconfig.json va vite.config.js'da sozlangan).

## Ishga tushirish

```bash
npm install
npm run dev
```
